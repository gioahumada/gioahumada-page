Turbo C Online lleva el clásico Turbo C a la web mediante una emulación de DOSBox-X ejecutada con WebAssembly. Así puedes escribir, compilar y ejecutar programas C en el navegador, sin instalar localmente el compilador ni las herramientas DOS.

## Características

- Editor de código basado en Monaco.
- Compilación y ejecución de programas C en un entorno DOS emulado.
- Persistencia del proyecto en el navegador.
- Interfaz disponible en español e inglés.
- Importación y exportación de archivos del proyecto.

Para adaptarlo a la web, se tomó el código de Turbo C y se comprimió para crear una versión compacta, eliminando la interfaz gráfica y los componentes innecesarios. Esta versión se ejecuta dentro de un entorno DOS emulado en el navegador mediante WebAssembly.
